<Badge color="blue">Sicherheits-Modul</Badge> <Badge color="green">Setup-Dauer: 2 Min.</Badge>

Das **Verifikations-Modul** bietet deinem Server einen robusten Schutzschild gegen automatisierte Bot-Angriffe und Raids. Neue Mitglieder müssen den Verifizierungsprozess erfolgreich durchlaufen, bevor ihnen Zugriff auf die Kanäle gewährt wird.

---

## Modul einrichten

Du kannst das Setup direkt über deinen Discord-Server oder ganz bequem über unser Web-Dashboard starten.

<Tabs>
  <Tab title="Via Discord-Befehl" icon="discord">
    <Steps>
      <Step title="Setup-Befehl ausführen">
        Führe auf deinem Server den Slash-Befehl `/verifikation_setup` aus.
      </Step>
      <Step title="Zielkanal festlegen">
        Wähle den Kanal aus, in dem die Verifizierungs-Nachricht (inklusive Interaktions-Button) gesendet werden soll.
      </Step>
      <Step title="Rollen zuweisen">
        Bestimme die zwei zentralen Rollen für das System:

        - **Unverified-Rolle:** Wird neuen Mitgliedern beim Beitritt zugewiesen (schränkt Rechte ein).
        - **Verified-Rolle:** Wird nach erfolgreicher Verifikation vergeben (schaltet Kanäle frei).
      </Step>
      <Step title="Sicherheitsstufe wählen">
        Wähle zwischen **Level 1**, **Level 2**, **Level 3** oder **Level 4**, um den Schutzfaktor festzulegen.
      </Step>
      <Step title="Optionen & Abschluss">
        Lege optional einen Log-Kanal fest und aktiviere `Auto-Unverified bei Join`. Klicke anschließend auf **Setup abschließen**.

        <Tip>
          Die Konfigurationsnachricht kann nach dem Abschluss gelöscht werden, sofern sie nicht `ephemeral` (nur für dich sichtbar) versendet wurde.
        </Tip>
      </Step>
    </Steps>
  </Tab>

  <Tab title="Via Web-Dashboard" icon="sliders">
    1. Logge dich im **Dashboard** ein und wähle deinen Server aus.
    2. Navigiere in der linken Menüleiste zum Punkt **Verifikation**.
    3. Aktiviere den Regler **Modul aktivieren**.
    4. Wähle deine Kanäle, Rollen und die gewünschte Sicherheitsstufe aus.
    5. Klicke unten rechts auf **Speichern**.
  </Tab>
</Tabs>

## Sicherheitsstufen (Verifikations-Level)

Wähle die passende Sicherheitsstufe für deine Community. Du kannst diese Stufen jederzeit im laufenden Betrieb anpassen:

<CardGroup cols={2}>
  <Card title="Level 1: DM + Button" icon="message">
    Der User klickt auf den Server-Button und erhält eine **Direktnachricht (DM)** vom Bot. Erst nach der Bestätigung in der DM wird die Rolle vergeben.
  </Card>

  <Card title="Level 2: Instant-Button" icon="bolt">
    Die schnelle **Sofort-Verifikation**. Ein einziger Klick auf den Button im Verifikations-Kanal schaltet den Server direkt frei.
  </Card>

  <Card title="Level 3: DM + Support-Server" icon="file-symlink">
    Höchster Schutz. Der User muss die DM bestätigen **und** zusätzlich Mitglied auf dem offiziellen Support-Server sein.
  </Card>

  <Card title="Level 4: DM + Zufallscode" icon="user-code">
    Der User klickt auf den Server-Button und erhält eine **Direktnachricht (DM)** vom Bot, in der ein zufälliger Code zur Bestätigung eingegeben werden muss.
  </Card>
</CardGroup>

## Einstellungen & Parameter

<AccordionGroup>
  <Accordion title="Kanäle & Rollen-Konfiguration" icon="network-wired">
    - **Verifikations-Kanal:** Der öffentlich sichtbare Kanal (z. B. `#🔑・verifikation`), in dem das Panel eingebunden wird.
    - **Log-Kanal (Optional):** Protokolliert Beitritte, erfolgreiche sowie fehlgeschlagene Verifikationsversuche.
    - **Unverified-Rolle:** Schränkt die Berechtigungen neuer Mitglieder temporär ein.
    - **Verified-Rolle:** Verleiht vollen Zugriff auf deine Community-Kanäle.
  </Accordion>

  <Accordion title="Erweiterte Optionen" icon="gear">
    - **Auto-Unverified bei Join:**
      - **Aktiviert (`Ja`):** Verweist jeden neuen Serverbeitritt automatisch in die _Unverified_-Rolle.
      - **Deaktiviert (`Nein`):** Mitglieder bleiben bis zur Verifikation ohne gesonderte Rolle.
    - **Sprachanpassung:** Passe die Sprache der Verifizierungs-Nachrichten individuell an deine Zielgruppe an.
  </Accordion>
</AccordionGroup>

## Wichtige Admin-Hinweise

<Warning>
  **Rollen-Hierarchie beachten:** Stelle sicher, dass die Rolle des Bots in den Discord-Servereinstellungen **über** der _Verified_- und _Unverified_-Rolle platziert ist. Andernfalls kann der Bot keine Rollen zuweisen oder entfernen!
</Warning>

<Note>
  **Best Practice zur Rechtevergabe:** Konfiguriere die Berechtigungen der `Unverified`-Rolle so, dass Mitglieder **ausschließlich** den Verifikations-Kanal sehen und lesen können. Alle anderen Kanäle sollten für diese Rolle komplett ausgeblendet sein.
</Note>
